# Expenses-Tracker-
I built this expense tracker using AI to help me, as a student, manage my money and track my daily spending. 💙 **My Student Wallet** is a student-friendly finance tracker built using HTML, CSS, and JavaScript.

✨ **Main Features:**✨
- 💰 **Balance Management** – Set and edit your starting balance.
- 📊 **Income & Expense Tracking** – Monitor total income, expenses, and remaining balance.
- 🧾 **Transaction Management** – Add, view, and delete transactions.
- 🏷️ **Category-wise Breakdown** – Track spending on food, travel, study, fun, and other expenses.
- 🌙 **Dark Mode** – Switch between light and dark themes.
- 💾 **Local Storage** – Save transactions and balance in your browser.
- 📱 **Responsive Design** – Enjoy a clean, pastel-themed interface across different screen sizes.

This project combines my personal need for better money management with my interest in web development and AI-assisted coding. ✨
